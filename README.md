Project Name

Simple Interest Calculator

Description

This project is a Bash-based calculator that computes simple interest based on user-provided values.

The user enters:

- Principal amount
- Rate of interest
- Time period

The script then calculates the simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

Features

- Accepts principal amount as input.
- Accepts rate of interest as input.
- Accepts time period as input.
- Calculates and displays the simple interest.
- Simple and easy-to-use Bash script.

Technologies Used

- Bash Shell Scripting
- Git
- GitHub

Project File

The main program is:

"simple-interest.sh"

How to Run

Clone the repository:

git clone <YOUR-GITHUB-REPOSITORY-URL>

Navigate to the project directory:

cd <YOUR-REPOSITORY-NAME>

Give execution permission:

chmod +x simple-interest.sh

Run the script:

./simple-interest.sh

Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period
